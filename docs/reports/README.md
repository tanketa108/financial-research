# Reports

Place full thesis / investment write-up artifacts here so company pages can expose durable download links.

## Supported naming conventions

For ticker `UBER`, any of these will be detected automatically:

- `UBER-thesis-report.pdf`
- `UBER-thesis-report.html`
- `UBER-thesis-report.md`
- `UBER-investment-thesis.pdf`
- `UBER-investment-thesis.html`
- `UBER-investment-thesis.md`

The company page will render available files as download chips under **Full thesis report**.

## Recommendation

Prefer:
- HTML for readable in-browser reports
- PDF for final archive/download
- Markdown as the lightweight source artifact
